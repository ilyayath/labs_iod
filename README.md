У кожній папці лежать ноутбук `labN.ipynb`, вхідні дані в `data/`, звіт `.docx` і методичка.

## Запуск

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

Ноутбук відкривати з його папки (наприклад `lab1/lab1.ipynb`), бо шлях до даних відносний: `data/...`.
